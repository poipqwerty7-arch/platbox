# Platbox 🎮

Прототип игровой платформы вроде Roblox: сайт-платформа (регистрация, аккаунты, каталог игр) + игровой 3D-клиент на Godot, который заходит под тем же аккаунтом.

**Бэкенд и база данных живут в облаке (Railway)** — см. `DEPLOY.md` для пошагового деплоя. Это значит, что играть можно с любого устройства и в любой сети, а не только с одного ноута.

## Структура проекта

```
platbox/
├── DEPLOY.md          Пошаговый деплой на Railway
├── backend/           Node.js API-сервер: авторизация, БД, список игр
│   ├── server.js      HTTP-сервер и роуты (асинхронные, Postgres)
│   ├── db.js          Подключение к Postgres (через переменную DATABASE_URL)
│   ├── auth.js        Хэширование паролей (scrypt) + JWT-токены
│   ├── railway.json   Конфиг деплоя для Railway
│   └── .env.example   Шаблон переменных окружения
├── web/                Веб-страница платформы (лендинг + вход/регистрация + каталог)
│   ├── index.html
│   └── app.js
└── godot-client/       Игровой 3D-клиент (Godot 4.3+)
    ├── project.godot
    ├── scenes/
    │   ├── login.tscn       экран входа/регистрации
    │   ├── game_lobby.tscn  список игр из API
    │   └── world.tscn       3D-мир с персонажем
    └── scripts/
        ├── session.gd       автозагрузка: токен, адрес API, запросы
        ├── login.gd
        ├── game_lobby.gd
        ├── player.gd        движение, прыжок, камера
        ├── touch_controls.gd виртуальный джойстик для телефона
        └── world.gd
```

## 1. Задеплой бэкенд на Railway

Подробно — в `DEPLOY.md`. Коротко: создать проект на Railway, добавить Postgres, задеплоить `backend/`, подключить `DATABASE_URL`, сгенерировать публичный домен.

## 2. Локальный запуск (для разработки/отладки)

Нужен **Node.js 18+** и Postgres (локально или облачный — например, тот же Railway).

```bash
cd backend
npm install
# создай .env по образцу .env.example с DATABASE_URL и JWT_SECRET
node server.js
```

Проверить, что всё работает:
```bash
curl http://localhost:3000/api/games
```

## 3. Открыть веб-версию платформы

Сервер раздаёт статику из `web/`, так что сайт доступен прямо на адресе бэкенда:
- после Railway-деплоя: `https://твой-проект.up.railway.app`
- локально: `http://localhost:3000`

Там можно зарегистрироваться, войти, посмотреть каталог игр — это и есть "сайт" Platbox.

## 4. Запуск игрового 3D-клиента (Godot)

1. Установи **Godot 4.3+** (https://godotengine.org/download) — бесплатный, ничего покупать не надо.
2. Открой Godot → Import → выбери `godot-client/project.godot`.
3. Нажми ▶ (F5) — запустится сцена входа.
4. Зарегистрируйся или войди тем же аккаунтом, что и на сайте (общая база данных!).
5. В лобби нажми "Играть" на любой карточке — попадёшь в 3D-мир с платформами.

**Управление на ПК:** WASD — движение, мышь — камера, Space — прыжок, Esc — освободить курсор.
**Управление на телефоне:** виртуальный джойстик слева, кнопка "ПРЫЖОК" справа снизу (появляются автоматически на мобильной сборке).

### Важно про адрес сервера
В `godot-client/scripts/session.gd`:
```gdscript
const RAILWAY_URL := "https://твой-проект.up.railway.app/api"
const LOCAL_URL := "http://127.0.0.1:3000/api"
const USE_REMOTE := true  # true = Railway, false = локальный сервер
```
Замени `RAILWAY_URL` на свой реальный адрес после деплоя (см. `DEPLOY.md`). Для локальной отладки без интернета переключи `USE_REMOTE` на `false`.

## 4. Экспорт под платформы

В Godot: **Project → Export**. Уже настроены пресеты (`export_presets.cfg`) под:
- Windows / Linux (десктоп)
- Android (нужен Android SDK + Java, Godot попросит настроить путь при первом экспорте)
- Web (HTML5, можно залить на любой статический хостинг)

## Что уже работает

- ✅ Регистрация и вход (пароли хэшируются scrypt, сессии — JWT-токены)
- ✅ Общий аккаунт между сайтом и игрой (одна база данных в облаке)
- ✅ Каталог игр с счётчиком запусков
- ✅ 3D-персонаж: ходьба, прыжок, камера от третьего лица, платформы
- ✅ Управление и мышью/клавиатурой, и тач-джойстиком (для телефона)
- ✅ Экспорт под Windows/Linux/Android/Web из коробки (Godot)
- ✅ Бэкенд и БД в облаке (Railway + Postgres) — доступ с любого устройства

## Что стоит добавить дальше (когда будешь развивать)

- Настоящий редактор уровней (свои "игры" от пользователей, а не один демо-мир)
- Мультиплеер (Godot High-Level Multiplayer API или WebSocket)
- Аватары/скины персонажа
- Магазин на внутриигровую валюту (`coins` уже есть в схеме БД)
- Модерация контента, если пользователи смогут заливать свои игры

## Технические детали, которые могут пригодиться

- **Пароли**: не хранятся в открытом виде — `scrypt` с солью на пользователя.
- **Токены**: собственная HS256-реализация JWT на встроенном `crypto`, живут 7 дней.
- **База данных**: Postgres (Railway), схема создаётся автоматически при первом запуске.
- Единственная npm-зависимость бэкенда — `pg` (клиент Postgres).
